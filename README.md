# Amphonix 2 Preset Maker (Android)

App Android (WebView, funciona offline) que monta presets para o Sonicake Amphonix 2 com firmware CFW:
cadeia NR → FX1 → DRV → AMP → IR → EQ → FX2 → DLY → RVB, com todos os modelos nativos, SB e CFW.

O APK é gerado automaticamente pelo GitHub Actions a cada push na `main` e publicado em **Releases** (`AmphonixPresetMaker.apk`).
